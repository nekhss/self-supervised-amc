# DL-Project report draft

- `report.tex`: LaTeX source (draft). Build with `latexmk -pdf report.tex`; it needs `references.bib`, `figures/` and `tables/`.
- `report.pdf`: compiled draft, for review only.
- `references.bib`: four canonical references. Verify each one before submission.
- `figures/`: PDF (vector) and PNG versions of every figure.
- `tables/*.tex`: table bodies, generated by the build script.
- `tables/values.json`: every number used, for checking.
- `evidence_map.md`: each claim, its source file, and its verification status.
- `scripts/build_report_assets.py`: regenerates `figures/` and `tables/` from `C:\dlruns`. It reads files only; it trains nothing and evaluates nothing.

  Run from this folder:

  `C:\venvs\dlproj\Scripts\python.exe scripts\build_report_assets.py --dlruns C:\dlruns --out .`
- `scripts/check_report_numbers.py`: checks every number in the prose against `tables/values.json`.

Red "Review:" notes in the PDF mark items that still need the author's input or verification.
