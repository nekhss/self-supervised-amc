# Evidence map: DL-Project report draft

Every quantitative claim in `report.tex` maps to a stored source below. Paths are relative to `C:\dlruns` unless they start with `DL-Project\`.

All tables are generated by `report\scripts\build_report_assets.py`, which reads only these files. That script asserts run identity (arm, budget, seed, test size), and that the per-epoch diagnostics reproduced the logs and epoch-5 weights. `report\scripts\check_report_numbers.py` checks every number in the prose against `report\tables\values.json`. Its last run left only the identifiers `2018.01`, `4050` and `3.16` unmatched; `480` is the tail of "12,480", which the checker splits.

Status column:

- **verified**: read from the stored file by me during this audit.
- **derived**: computed from verified files or source code.
- **transcript**: appears only in console output from this session, with no stored file. Flagged in the report.
- **inferred**: not recorded anywhere; deduced from code history. Flagged.
